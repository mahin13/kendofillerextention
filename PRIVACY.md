# Privacy Policy — Kendo Filler

Last updated: 27 August 2026

## Summary

Kendo Filler does not collect, store, transmit, or sell any user data.

## What the extension does

Kendo Filler is a developer and QA tool. When you click its toolbar button, it
inspects the form controls on the page you are currently viewing and fills them
with generated test data. It does this entirely within your own browser.

## Data we collect

None.

Specifically, Kendo Filler does not collect or transmit:

- Personally identifiable information
- Health information
- Financial or payment information
- Authentication information, passwords, or credentials
- Personal communications
- Location data
- Browsing or web history
- User activity, clicks, or keystrokes
- Website content

## Data the extension stores locally

Kendo Filler saves one configuration object containing your own extension
settings — your chosen fill mode, which control categories are enabled, the
numeric and decimal ranges, and your theme preference.

This is stored using the browser's own extension storage. If you are signed in
to your browser, the browser itself may synchronise these settings across your
devices; that synchronisation is performed by your browser, not by us, and the
data never reaches any server we operate.

No page content and no field values are ever stored.

## Network activity

Kendo Filler makes no network requests of any kind. It contains no analytics, no
telemetry, no crash reporting, and no advertising. It loads no remote code — all
of its code is contained in the published extension package.

## Page access

Kendo Filler requests no host permissions. It uses the `activeTab` permission,
which grants access to a page only for the tab you are on and only after you
explicitly click the extension's toolbar button. It cannot read any page you
have not invoked it on, and it does nothing in the background.

## Third parties

Kendo Filler shares no data with anyone, because it collects none. No data is
sold or transferred to third parties, used for any purpose unrelated to the
extension's single purpose, or used to determine creditworthiness or for lending
purposes.
