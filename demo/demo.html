Kendo Filler — demo & test page

Checking Kendo UI…

To test against real Kendo widgets: Chrome does not allow extensions to inject scripts into chrome-extension:// pages, and the extension CSP blocks the Telerik CDN here. Serve the extension folder over http and open this page from there — e.g. npx http-server . -p 8080 (or python -m http.server 8080), then visit http://localhost:8080/demo/demo.html. Every native control below works either way.
